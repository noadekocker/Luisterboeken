# Luisterboek

Een eenvoudige audioboek-speler voor m4b-bestanden, gemaakt voor de iPhone.

- Toont alle hoofdstukken uit het m4b-bestand
- Speelt verder als je scherm vergrendeld is of je een andere app opent
- Onthoudt waar je gestopt bent
- Hoofdstukken handmatig afvinken als voltooid
- Snelheid, slaaptimer, 15 sec terug / 30 sec vooruit

Je audioboeken worden niet geüpload: ze blijven op je eigen toestel.

**Gebruik:** open de site in Safari → deelknop → *Zet op beginscherm*.
